# Third-party notices and provenance review

IP-Orch's MIT license text previously carried the attribution:

Copyright (c) 2011-2026 The Bootstrap Authors

That attribution was replaced in the root LICENSE with IP-Orch contributors,
matching the project identity and authors listed in pyproject.toml and the
Zenodo software record. This file retains the historical notice rather than
silently erasing it. It does not imply that Bootstrap authored IP-Orch.

The audit searched tracked text for copyright, Bootstrap and license notices.
No separately marked Bootstrap-derived source was found. This is a text-based
review, not a complete provenance determination for unmarked copied code.
Maintainers must confirm institutional ownership and disclose any incorporated
third-party source. Preserve that source's complete original notices if found.
The MIT permission and warranty text in LICENSE is retained unchanged.

MLIP backends are optional external dependencies with their own software and
checkpoint licenses. The IP-Orch license does not relicense those artifacts.
Users must consult their upstream terms before redistributing backend weights.
