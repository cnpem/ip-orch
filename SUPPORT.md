# Support

Report bugs and ask usage questions through
https://github.com/cnpem/ip-orch/issues. Follow the reproduction guidance in
[CONTRIBUTING.md](CONTRIBUTING.md). Search existing issues first.

Maintenance is provided on a best-effort basis; there is no guaranteed response
time or service-level agreement. Backend-specific failures may require upstream
support. Include the backend version, checkpoint and complete traceback so the
failure can be routed appropriately.
